Hello Sample is a frontend-only Vite + React 19 single-page application generated by the Quorq AI SDLC platform. It renders approved screens using seeded sample data with no backend or network calls. The codebase uses TypeScript, Tailwind CSS 4, React Router DOM 7, Vitest for unit/component tests, and Playwright for end-to-end tests, with ESLint and Prettier for linting and formatting.

<!-- sdlc:auto:start conventions -->
- Screens are one module per approved screen under src/screens/
- Navigation shell and route table live in src/App.tsx
- Shared UI components and icons are centralized in src/lib/ui.tsx and src/lib/icons.tsx
- Brand tokens and CSS variables live in src/lib/brand.ts and src/index.css
- Import alias @/* maps to ./src/* via both Vite and tsconfig
- Component tests live beside the components they cover, scoped to src/**
- Playwright specs live in the e2e/ folder and are excluded from Vitest collection
- API integration seam is src/lib/api.ts, which screens do not use yet (they render seeded sample data)
- No real credentials are committed; API_PROJECT_ID and VITE_API_BASE_URL are set at build time by the platform
<!-- sdlc:auto:end conventions -->

<!-- sdlc:auto:start troubleshooting -->
| Problem | Solution |
|---|---|
| npm run build succeeds but npm run typecheck fails | Build does not run tsc. Run npm run typecheck separately and fix reported type errors before maintaining the codebase. |
| Playwright tests fail with browser not found | Run npm run test:e2e:install to download Chromium first. |
| Playwright tests fail when E2E_BASE_URL is not set | Without E2E_BASE_URL, Playwright builds and serves the app on port 4173. Ensure port 4173 is free or set E2E_BASE_URL to a deployed URL. |
| Vitest collects Playwright specs and fails | Vitest is scoped to src/** and should not collect e2e/ specs. If it does, verify vite.config.ts test.include only matches src/**/*.{test,spec}.{ts,tsx}. |
| Chromium crashes in a container during e2e tests | The Playwright config already passes --disable-dev-shm-usage. Ensure you are using the configured chromium project. |
<!-- sdlc:auto:end troubleshooting -->
